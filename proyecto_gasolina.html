knit_print.summary.lm <- function(x, ...) {
  coeficientes <- tabla_html(x$coefficients, digits = c(4, 4, 3, 5))

                       F = x$fstatistic[1], gl = x$df[2],
                       Error_residual = x$sigma, row.names = NULL)
  asis_output(paste0(coeficientes, tabla_html(ajuste, digits = 4)))
}

Paso 2: estimar el modelo

Logaritmos para que los coeficientes salgan como elasticidades: si precio sube tanto porcentaje, consumo baja otro tanto.

Modelo: \(\ln(Consumo) = \beta_1 + \beta_2 \ln(Precio) + \beta_3 \ln(PIB) + u\)

Code 
datos$ln_consumo <- log(datos$consumo_gasolina_pj)
datos$ln_precio  <- log(datos$precio_real_gasolina)
datos$ln_pib     <- log(datos$pib_real_mmdp)

Un coeficiente de 0.24 positivo, como suponíamos, es lo contrario a la teoría.

Regresión múltiple (precio y PIB)

Ahora rescatamos una interpretación diferente, ya que al meter al PIB cambia el signo del coeficiente del precio, así que era el PIB el que movía ambos factores.

Precio: -0.94; si el precio sube 1%, el consumo baja 0.94%.

PIB: 2.63; si el PIB sube 1%, el consumo sube 2.63%.

P-valores menores a 0.05, es decir que ambas variables sí influyen.

R²: 0.74, es decir que el modelo está explicando 74% de los cambios respecto al consumo.

El p-valor de F igual es menor que 0.05, por lo que el modelo en conjunto sí demuestra funcionar.

Gl: 17, debido a que usamos 3 de nuestros datos por los 3 coeficientes. Los que usamos para buscar los valores de la tabla.

Otro dato clave es el error estándar residual, 0.065, que nos dice que el modelo se equivoca en promedio 6.5%.

Prueba F global, calculada con el R²

\[F = \frac{R^2/(k-1)}{(1-R^2)/(n-k)}\]

En base a H₀ suponemos que el modelo no explica nada; sin embargo, la F calculada es mucho mayor que lo que habíamos establecido antes, por lo cual se rechaza: el precio y el PIB juntos sí pueden explicar el consumo de gasolina.

R2 <- summary(modelo)$r.squared
F_calc <- (R2 / (k - 1)) / ((1 - R2) / gl)

Paso V: estadístico F

\[F = \frac{(SCR_R - SCR_{NR})/k}{SCR_{NR}/(n_1 + n_2 - 2k)}\]

La F de Chow es menor que el valor de tablas (3.34), por lo cual no se rechaza H₀.

No hay evidencia estadística para decir que la demanda de gasolina haya cambiado en 2017.

Tenemos el mismo problema antes mencionado: con pocos datos no alcanzamos a asegurarlo.

La prueba de Chow es válida, pues los ruidos de los dos periodos son parecidos (2.76 contra 3.59).

Code 
n1 <- nrow(antes)
n2 <- nrow(despues)

F_chow <- ((SCR_R - SCR_NR) / k) / (SCR_NR / (n1 + n2 - 2 * k))
F_chow
[1] 1.85552
Code 
F_critico <- qf(0.95, k, n1 + n2 - 2 * k)
F_critico
[1] 3.343889

Supuesto de varianzas iguales

\[F = \frac{\hat\sigma_2^2}{\hat\sigma_1^2} \qquad \hat\sigma_1^2 = \frac{SCR_1}{n_1 - k}, \quad \hat\sigma_2^2 = \frac{SCR_2}{n_2 - k}\]

Ahora vamos a trabajar con las varianzas para verificar si es válida la prueba de Chow.

Code 
var1 <- SCR_1 / (n1 - k)
var2 <- SCR_2 / (n2 - k)

F_var <- var2 / var1
F_var
[1] 2.757507

La F de varianza es de 2.76, menor que 3.59; podemos considerar que son similares, por lo que la prueba de Chow es válida.

Code 
qf(0.95, n2 - k, n1 - k)
[1] 3.587434
